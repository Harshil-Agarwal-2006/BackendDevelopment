# PBL Assignment

## Student Management API - Docker and CI/CD

This PBL project implements a Student Management REST API using FastAPI and demonstrates containerization, automated testing, Docker Compose, Docker Hub, and CI/CD using GitHub Actions.

### Features Implemented

- Student Management REST API using FastAPI
- CRUD operations for students
- Health check endpoint
- Structured request logging
- Automated API route testing using `automationTesting.py`
- Application containerization using Docker
- Service execution using Docker Compose
- Docker image publishing to Docker Hub
- CI/CD pipeline using GitHub Actions
- Automated testing before Docker image build and push

### CI/CD Pipeline

`Code Push → GitHub Actions → Automated Tests → Docker Build → Docker Hub Push`
