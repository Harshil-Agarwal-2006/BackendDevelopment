# Experiment 1 – Personal Introduction Web Page

## Overview

This experiment involves creating a personal introduction web page using HTML. The page demonstrates the use of common HTML tags and semantic elements to organize personal information, skills, projects, interests, and other details in a structured format.

## Technologies Used

- HTML5

## Project Structure

- `Lab1.html` – Main HTML file containing the complete personal introduction webpage.
- `README.md` – Project documentation file.

## Key Features

1. Displays a personal introduction with name and professional interests.
2. Provides navigation links to different sections of the webpage.
3. Displays programming, development, creative, and marketing skills.
4. Presents projects using semantic `<article>` elements.
5. Uses ordered, unordered, and description lists.
6. Displays information using an HTML table.
7. Demonstrates text formatting elements such as bold, emphasis, highlighting, and abbreviations.
8. Uses semantic HTML elements such as `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, and `<footer>`.
9. Includes internal navigation using section IDs and anchor links.
10. Demonstrates additional HTML elements such as `<blockquote>`, `<pre>`, `<mark>`, and `<small>`.

## Concepts Covered

- Basic HTML document structure.
- Semantic HTML5 elements.
- Headings and paragraphs.
- Text formatting tags.
- Ordered and unordered lists.
- Description lists.
- Internal navigation using anchor links.
- Tables and structured data.
- Sections and articles.
- HTML entities and abbreviations.
- Metadata and viewport configuration.

## Learning Outcomes

- Understand the basic structure of an HTML document.
- Create structured webpages using semantic HTML elements.
- Organize content using headings, paragraphs, lists, and sections.
- Implement internal webpage navigation using anchor links.
- Display tabular information using HTML tables.
- Apply different HTML text formatting elements.
- Develop a simple personal profile webpage using HTML.

## Conclusion

This experiment demonstrates the fundamentals of HTML by creating a structured personal introduction webpage. It covers commonly used HTML tags, semantic elements, navigation, lists, tables, and text formatting techniques required for building basic web pages.
