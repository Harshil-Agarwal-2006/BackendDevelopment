# Experiment 15 – Django Task Tracker

## Overview

This experiment involves developing a Task Tracker web application using Django and SQLite. It allows users to manage tasks through a simple web interface.

## Technologies Used

- Python
- Django
- SQLite
- HTML
- CSS
- JavaScript

## Project Structure

- `django_todo_app/` – Main project directory.
- `todo_project/` – Django project configuration.
- `todo/` – Main task management application.
- `models.py` – Task database model.
- `views.py` – Application logic.
- `urls.py` – URL routing.
- `templates/` – HTML templates.
- `static/` – CSS, JavaScript and image assets.
- `db.sqlite3` – SQLite database.

## Key Features

1. Add new tasks.
2. View the task list.
3. Update and delete tasks.
4. Store tasks in SQLite.
5. Use Django templates with template inheritance and includes.
6. Manage tasks through the customized Django Admin panel.
7. Responsive user interface using CSS.

## Concepts Covered

- Django project and application structure.
- Models and database migrations.
- Views and URL routing.
- CRUD operations.
- Django templates.
- Static files and CSS.
- Django Admin.

## Learning Outcomes

- Develop web applications using Django.
- Integrate SQLite databases.
- Implement CRUD functionality.
- Work with templates and static files.
- Manage application data through Django Admin.

## Conclusion

This experiment demonstrates the development of a Django-based Task Tracker with database integration, CRUD operations and a responsive web interface.
