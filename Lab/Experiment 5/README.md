# Experiment 5 – JavaScript Arrays, Objects and Functions

## Overview

This experiment demonstrates the use of JavaScript arrays, objects, and functions. It covers basic operations such as storing and modifying data, accessing values, and creating reusable functions for performing different operations.

## Technologies Used

- JavaScript
- Node.js

## Project Structure

- `script.js` – Main JavaScript file containing examples of arrays, objects, and functions.

## Key Features

1. Create and display a JavaScript array containing student names.
2. Access individual elements from an array.
3. Add elements to an array using `push()`.
4. Remove elements from an array using `pop()`.
5. Determine the number of elements using the `length` property.
6. Create a JavaScript object containing student information.
7. Access and modify object properties.
8. Add new properties to an existing object.
9. Create and call JavaScript functions.
10. Pass parameters to functions and return calculated values.

## Concepts Covered

- JavaScript arrays.
- Array indexing.
- Array methods such as `push()` and `pop()`.
- Array `length` property.
- JavaScript objects.
- Object properties and values.
- Accessing and modifying object properties.
- Adding properties dynamically.
- Function declaration and invocation.
- Function parameters.
- Return values.
- Basic arithmetic operations using functions.
- Console output using `console.log()`.

## Learning Outcomes

- Understand how arrays are used to store multiple values in JavaScript.
- Perform basic operations on arrays.
- Create and manipulate JavaScript objects.
- Access, update, and add object properties.
- Understand the purpose of functions in JavaScript.
- Create functions with and without parameters.
- Return values from functions.
- Execute JavaScript programs and observe results through the console.

## Conclusion

This experiment demonstrates the fundamentals of JavaScript arrays, objects, and functions. It provides practical experience in storing and manipulating data, organizing related information using objects, and creating reusable blocks of code using functions.
