# Experiment 7 & 8 – ES6 To-Do List Application

## Overview

This experiment involves developing a simple To-Do List application using HTML, CSS, and modern JavaScript (ES6). The application allows users to add tasks, mark tasks as completed, and delete tasks through an interactive web interface.

The experiment demonstrates ES6 concepts along with DOM manipulation and event handling in JavaScript.

## Technologies Used

- HTML5
- CSS
- JavaScript (ES6)

## Project Structure

- `index.html` – Main webpage containing the To-Do List interface and CSS styling.
- `app.js` – JavaScript file containing task management logic, DOM manipulation, and event handling.

## Key Features

1. Add new tasks to the To-Do List.
2. Add tasks by clicking the **Add** button.
3. Add tasks by pressing the **Enter** key.
4. Mark tasks as completed by clicking on them.
5. Display completed tasks using a strike-through style.
6. Delete individual tasks using the **Delete** button.
7. Dynamically render the task list using JavaScript.
8. Generate a unique ID for each task using `Date.now()`.
9. Manage tasks using an in-memory JavaScript array.
10. Update the user interface automatically whenever the task list changes.

## ES6 Features Used

- `let` and `const` for variable declarations.
- ES6 classes and constructors.
- Arrow functions.
- Spread operator (`...`).
- Object destructuring.
- Array methods such as `forEach()`, `map()`, and `filter()`.
- Template-independent dynamic DOM creation.
- Event objects and keyboard events.

## Concepts Covered

- JavaScript classes and objects.
- DOM selection using `getElementById()`.
- Dynamic DOM element creation.
- Event listeners.
- Event delegation.
- Keyboard event handling.
- Array manipulation.
- State management using arrays.
- Conditional rendering.
- CSS class manipulation.
- Dataset attributes.
- Form input validation.
- Updating application state without reloading the webpage.

## Learning Outcomes

- Understand and apply modern ES6 JavaScript features.
- Create reusable objects using JavaScript classes.
- Manipulate arrays using `map()`, `filter()`, and `forEach()`.
- Dynamically create and update HTML elements using JavaScript.
- Handle mouse and keyboard events.
- Implement event delegation for dynamically generated elements.

## Conclusion

This experiment demonstrates the development of an interactive To-Do List application using ES6 JavaScript. It combines modern JavaScript features such as classes, arrow functions, destructuring, spread operators, and array methods with DOM manipulation and event handling to implement task creation, completion, and deletion functionality.
